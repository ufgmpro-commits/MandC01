# MandC01

Bu depo, projenin bilgisayardan bağımsız ana kaynağıdır.

## Çalışma düzeni

- Anlamlı tüm kod ve dokümantasyon değişiklikleri GitHub'a commit edilip gönderilir.
- Yeni işler ayrı branch üzerinde hazırlanır ve mümkün olduğunda pull request ile birleştirilir.
- `main` dalı çalışır ve devam edilebilir durumda tutulur.
- Yerel bilgisayara özgü dosyalar, parolalar, erişim anahtarları ve diğer gizli bilgiler commit edilmez.
- Kurulum, çalıştırma, test ve dağıtım komutları proje geliştikçe bu depoda belgelenir.
- Yarım kalan işlerde mevcut durum, sonraki adım ve bilinen sorunlar `STATUS.md` dosyasında tutulur.

## Başka bir bilgisayarda devam etme

```powershell
git clone https://github.com/ufgmpro-commits/MandC01.git
cd MandC01
```

Ardından bu dosyadaki kurulum yönergelerini ve varsa `STATUS.md` dosyasını izleyin.
